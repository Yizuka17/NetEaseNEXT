# NetEaseNEXT

原生 C# / XAML WinUI 3 网易云音乐客户端，支持 Windows 10 2004 及以上。

## 使用

[下载安装包](https://github.com/Yizuka17/NetEaseNEXT/releases/latest)。默认安装包为 MSIX，由 Windows 管理安装目录和开始菜单入口。便携版仍可解压后运行 `NetEaseNEXT.exe`，保留目录内所有文件。

- 在歌曲菜单打开歌手详情：热门50、专辑、MV、歌手详情。搜索只在发现页显示，Ctrl+F 可回到主页搜索。
- 歌单详情展示封面、简介、标签和创建者，打开时有封面过渡。支持收藏歌单、歌单评论，以及创建公开或私密歌单；自己的歌单可删除、移除曲目和调整顺序。添加歌曲到歌单使用“文件夹＋”图标。
- 独立播放页：左侧封面、进度和控件，右侧双语歌词；封面取色仅作用于此页面。全屏沿用同一页面，通过原生窗口边界切换。空格播放/暂停，Ctrl+←/→ 切歌，Ctrl+↑/↓ 调整音量；播放页 ←/→ 跳转 5 秒。F11 切换全屏，Esc 退出，Alt+← 返回，Ctrl+F 搜索。
- 歌词平滑居中跟随，当前行以主题色突出显示，上下行渐淡。手动滚动后暂停跟随，点击“回到当前歌词”恢复，也可点击歌词跳转。大播放页不显示应用标题文字，顶部可拖动，右上角提供原生最小化、最大化/还原和关闭按钮；全屏隐藏窗口按钮、返回键并清除顶部拖动区域。
- 播放栏控件居中。顺序点击切换并提示；播放列表面板再次点击可收起。支持收藏到自己的歌单、红心及真实红心总数、音质和下载；歌单及播放列表内提供定位当前歌曲的浮动按钮；音量在播放栏，输出设备与系统音效在设置。音质选择立即保存偏好并提示下一首生效，当前歌曲不中断；播放栏显示接口实际返回的音质。下载仍受账号权限限制。
- 歌曲评论区支持阅读、分页、发表、回复和点赞。动态也可查看评论、评论和点赞；通知展示评论原文，通知、评论回复和提及按时间合并展示；私信单独展示。账号菜单分别显示未读数，未读条目左侧显示圆点。点赞与回复放在每条评论内，加载更多位于列表最底部。
- 手机扫码登录。登录后显示头像和名称，点击可查看消息、私信。私信支持表情、文字回复及歌曲、专辑、歌单分享；当前不提供图片发送。侧栏提供动态与“我的播客”，展示账号订阅的播客，节目可直接播放。
- 点击动态、私信等里的歌曲卡片，会将歌曲插入当前歌曲的后一首并立即切换播放。已在列表中的歌曲会移动到该位置，其他歌曲顺序保留；随机播放不会重新洗牌。
- 设置分为常规、外观、播放与音效、存储，支持字体、材质透明度、缓存目录、下载目录和关闭到托盘。
- 歌曲单击保留已有队列并播放当前曲目，双击用所在列表替换队列，触摸支持两次快速点击；右键或系统触摸长按可添加至下一首播放。播放列表也有歌曲菜单。
- 歌单及播放列表的歌曲菜单提供“多选”，支持全选当前已加载歌曲、按显示顺序添加至下一首、批量收藏和下载；自己创建的歌单可批量移除，播放列表移除时保留正在播放的歌曲。点击“完成”或按 Esc 退出多选。
- 跟随系统时，评论、其他弹窗、菜单、标题栏按钮及播放页背景随深浅模式变化；设置为固定深色或浅色时保持所选模式。
- 歌单内的正在播放歌曲即使尚未加载，也会显示悬浮定位按钮；点击后按歌单索引自动分批补齐并滚到该歌曲，保留歌曲顺序及多选。侧栏歌单使用音符、播客使用耳机、专辑使用 Fluent Album，普通态和实心态都来自包内字体。
- 托盘后台播放，SMTC 系统媒体控制，单实例唤回。
- 退出后记忆歌曲、进度、歌单、队列和播放顺序；重启恢复为暂停。切入随机播放生成固定队列，切出恢复原顺序，再切回重新打乱。播放全部先开始第一首，再补齐歌单。

空间音效、音频增强按钮打开当前输出设备的 Windows 设置，具体选项由系统和驱动提供。Mica 需要 Windows 11，其取色来自桌面壁纸，不等同于透视窗口后方。系统不支持所选材质时使用纯色背景。

## 构建

需要 Windows、.NET 9 SDK、Node.js 22+。默认 x64。Windows App SDK 与构建工具由 NuGet 还原。

```powershell
pwsh -NoProfile -File scripts/build.ps1 -Publish
# 首次在本机生成并绑定 17 年签名证书；后续构建复用该证书
pwsh -NoProfile -File scripts/new-certificate.ps1
pwsh -NoProfile -File scripts/build-installer.ps1
```

便携包：`artifacts/win-x64`。已签名安装包与公钥证书：`artifacts/msix`。MSIX 使用 Windows SDK 的 MakeAppx、MakePri 和 SignTool；签名证书的 Subject 必须与 `packaging/AppxManifest.xml` 的 Publisher 一致。`build-installer.ps1` 默认构建已签名 MSIX，打包前核对清单图标路径、实际 PRI 候选资源与深浅色变体；`-Unsigned` 仅用于 CI 验证，输出带 `.unsigned` 后缀。可用 `scripts/run.ps1` 运行开发构建。

未单独安装 Windows SDK 时，可以用 `-SdkTools` 指定已还原的 SDK BuildTools 中包含 MakeAppx、MakePri、SignTool 的工具目录。

首次侧载自签名 MSIX，需将随包的 `NetEaseNEXT.cer` 信任到本机“受信任人”；这一步需要管理员权限。`install-msix.ps1 -TrustCertificate` 显式执行证书信任和安装，证书已信任时不需要该参数。后续安装同发布者、更高版本的包即可更新。迁移普通安装版时，从旧托盘退出后加 `-RemoveLegacyInstall`：先确认 MSIX 安装成功，再运行旧版卸载器并清理其两个旧快捷方式，不清除 `%LOCALAPPDATA%/NetEaseNEXT` 的账号、配置与缓存。MSIX 不再自行创建开始菜单快捷方式。

2026-10-15 任务栏与托盘主题修正版：`artifacts/win-x64-theme/NetEaseNEXT.exe`。先从旧版托盘退出，再启动新版；保留便携包内全部文件。任务栏和托盘图标随 Windows 系统颜色模式切换，暗色使用白色线条，浅色使用深色线条。托盘菜单使用原生 WinUI 主题资源。

后续菜单与启动响应修正版：`artifacts/win-x64-responsive/NetEaseNEXT.exe`。修复菜单点击外部不关闭，独立 API 读取并行，启动先显示缓存账号和头像，字体列表在打开设置时加载。

托盘菜单外圈描边修正版：`artifacts/win-x64-tray-border/NetEaseNEXT.exe`，保留此前修复，关闭菜单与窗口的两层外圈描边。

最新侧栏与托盘修正版：`artifacts/win-x64-native-tray/NetEaseNEXT.exe`。选中的侧栏图标显示实心，未选中保留线条；托盘改用 Win32 系统菜单，适配 Windows 深浅色，由系统处理外部点击收起、键盘导航和边框。

侧栏图标尺寸与动画修正版：`artifacts/win-x64-sidebar-fit/NetEaseNEXT.exe`。统一图标绘制范围，修复实心图标裁切；点击设置可旋转，再次点击也可触发，关闭动画时不播放，隐藏窗口时停止。

最新启动与动态修正版：`artifacts/win-x64-events-startup/NetEaseNEXT.exe`。元数据缓存统一 5 分钟，窗口创建与初始请求并行。消息支持查看来源歌曲、动态；动态页可查看我的动态，发布文字或分享当前歌曲。动态图片支持点开、双指缩放和拖动、滚轮缩放、双击还原与逐张查看；歌曲卡片点击加入播放列表。

## 验证

```powershell
pwsh -NoProfile -File scripts/verify.ps1 -Network
# 使用当前登录会话验证社交读取，不发送消息或写入互动
pwsh -NoProfile -File scripts/verify.ps1 -SocialRead
# 加测隐藏暂停状态和 Node 空闲退出
pwsh -NoProfile -File scripts/verify.ps1 -MeasureBackground
```

应用内检查覆盖真实 XAML、音频播放、歌词、暂停时列表滚动、全屏、歌手/专辑、订阅播客及材质回退。扫码确认需用户本人完成。Windows 11 材质实际观感、触屏交互及系统音效因设备而异，见 `verification` 中的验证记录。

## 数据与性能

侧栏“收藏的专辑”读取账号已有收藏，支持分页和进入专辑曲目；登录后自动刷新，退出账号时清除当前展示。自建歌单歌曲支持右键或触摸长按“从歌单移除”，服务器确认后更新列表，保留当前播放队列。播放栏的列表按钮直接展开当前队列。

账号会话以 Windows DPAPI 加密，绑定当前 Windows 用户，位于 `%LOCALAPPDATA%/NetEaseNEXT`。配置和限长日志也保存在此处。自选缓存目录保存封面、歌曲缓存和 API 临时状态，不移动账号凭据；旧目录不自动删除。封面按最近使用时间在 256 MiB 上限内整理，同图请求共享下载、损坏缓存自动重取。已解码封面的复用缓存上限为 32 MiB，隐藏窗口时保留；界面当前引用的图片也会继续保留，减少恢复时的重复解码。

歌曲缓存上限 1 GiB，按歌曲、实际音质和文件版本区分；完整下载并通过长度和 MD5 校验后保存。播放地址按会话和音质在内存中短期复用，遵守接口有效期，过期后重新请求，不写入磁盘。试听片段不保存为完整歌曲，此缓存不提供离线播放。下载目录只写入用户主动下载的歌曲。

前台提前请求可见曲目和队列邻近曲目的播放地址、详情，当前歌曲缓存完成后准备下一首完整音频和暂停的解码器；切歌时直接接管，减少等待。隐藏后停止额外预取、释放备用播放器。歌词、歌曲详情、歌单详情和列表等现有元数据缓存统一为 5 分钟；账号摘要、播放状态及落盘元数据用 DPAPI 保护。缓存账号摘要先显示，服务端登录态与初始页面请求在窗口创建期间并行进行，歌单归属核验不阻挡歌曲展示。

打开消息或私信条目会消除本地未读标记。两个列表右上角的“全部已读”会调用服务器的全局已读操作，清除消息和私信的全部提醒，保留消息内容。

音频由 Windows MediaPlayer 播放。列表虚拟化；封面根据 DPI 解码，UI 声明 Per-Monitor V2。模糊背景仅在换曲或主题变化后按需生成，不持续渲染动画。优化以后台 CPU 和唤醒次数为主。隐藏后停止界面进度、动画、消息轮询、封面处理及额外歌曲缓存下载，取消无用请求，保留完成的头像、封面、列表和歌词，恢复时复用；已解码封面的复用缓存仍有 32 MiB 上限，不主动清空或强制回收内存。API 使用私有管道，播放地址独立请求以减少页面加载的阻塞；Node 按需启动，15 秒空闲退出，不监听端口，不启用替代音源。

## 参考与依赖

- 应用内图标随包附带 MIT 许可的 [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) 字体子集，覆盖应用使用的图标和 WinUI Symbol 别名；不依赖系统安装 Segoe Fluent Icons。来源、固定版本和许可位于 `third-party/fluent-system-icons`，需要重新生成时运行 `scripts/generate-icon-font.py`（fonttools 4.67.0）。
- [Myune Music](https://github.com/xiaobaimc/myune_music)：参考播放栏、封面与歌词布局、封面模糊和取色处理思路，独立以 WinUI 3 实现，未复制源码或资源。
- [无羁音乐播放器](https://github.com/LanZhan-Harmony/WindowsMusicPlayer-TheUntamedMusicPlayer)：参考原生 Fluent 交互与短时动画。
- [Enhanced API](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)，固定 npm 版本 4.41.1。
- Microsoft Windows App SDK、Win2D、.NET；分发的 Node 许可位于 `third-party`，npm 依赖许可保留在 `api/node_modules`。

应用自行定义的图标显式使用包内字体，包括侧栏的空心与实心状态；侧栏图标颜色绑定导航项前景色。WinUI 原生控件模板对未包含的符号保留系统回退，Windows 标题栏与系统菜单仍由系统绘制。

`scripts/new-certificate.ps1` 生成有效期 17 年的 MSIX 签名证书并保存本机指纹绑定，后续运行复用该证书。私钥留在当前用户证书存储；`certificates` 不进入源码仓库，安装包只附带公钥 `.cer`。生成证书和签名不会自动更改系统信任。
