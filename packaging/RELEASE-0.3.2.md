本版汇总 0.2.8 之后的纯 C# 迁移、本地歌单和下载功能。0.3.0、0.3.1 为本机开发验收版本，本次一并发布。

- API 请求、加密和二维码改为纯 C#，运行与构建均不再需要 Node；音乐播放继续使用 Windows MediaPlayer。
- 本地音乐改为歌单封面卡片，可创建歌单、添加封面、绑定文件夹。文件变化自动同步，也可手动刷新；移除歌单不会删除音乐文件。
- 下载前选择目标最高音质，不可用时向下寻找最高可下载音质。队列支持全部暂停、继续、取消和清空；失败任务在独立列表中重试或清除。
- 下载按钮右下角显示已下载对勾，再次点击可选择升级音质。没有更高可用音质时保留现有文件；成功升级另存并保留旧版。同一目标目录内避免重复下载，不同目录各保存一份，便于按歌单分类。批量下载使用设置中的目标目录。
- 在线播放可直接匹配已下载歌曲及其实际音质，不再为该文件重复建立播放缓存。本地来源明确的下载歌曲可显示红心、评论和数量；“本地歌曲联网信息”默认开启，关闭或离线时隐藏入口。
- 下载来源可选择网易下载接口或 MusicUnlock 同款网易直连，使用当前网易登录凭据。实际可下载范围由账号权益与接口返回决定，直连模式不保证所有高阶音质。
- 移除播放器图标按钮的灰色衬底，整理评论关闭与发送位置，支持评论排序和发送成功后即时显示；补充字体文件导入、系统字体刷新、歌词自动回到当前行及滚动继续加载，并处理重复收藏提示和旧快捷方式迁移。

验证：Windows 10 x64，83 项 API 检查、28 项新增专项连续三轮通过；已安装 MSIX 的 28 项新增专项、32 项歌单/下载、22 项原生功能及 151 条完整回归记录无失败，未发现应用启动 Node 子进程。付费音源真实下载、远端互动写入和 Windows 11 尚未实机验收。

安装：已信任相同证书的用户可直接双击 `NetEaseNEXT-0.3.2.0-x64.msix` 更新。首次侧载请按 `INSTALL.txt` 信任随包公钥证书。脚本安装时将全部附件放在同一目录；迁移旧 EXE 版本可使用 `install-msix.ps1 -RemoveLegacyInstall -CloseRunningApp`。更新保留登录和本地歌单。
