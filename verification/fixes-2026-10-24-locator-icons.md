2026-10-24，0.2.8.0，保留 0.2.7 的主题与多选修复。源码与签名包对应 [GitHub Release v0.2.8](https://github.com/Yizuka17/NetEaseNEXT/releases/tag/v0.2.8)；0.2.7 未单独发布。

## 长歌单定位

原实现只在当前曲目已存在于 Tracks 时显示定位按钮，因此必须手动分页到该歌曲，才能看到按钮。此外，歌曲列表原有 1000 行上限会阻挡更后面的歌曲。

现在按歌单详情中的完整曲目 ID 索引判断归属：当前歌曲位于本歌单即可显示定位按钮，数据仍在加载时暂时禁用。点击后利用现有 song_detail 接口和缓存，每批最多 500 个 ID 补齐到目标，按原始歌单顺序添加并去重；后续“加载更多”接着正确偏移继续。歌单展示上限与已有详情索引上限一致，最多 10000 首，其他搜索等页面仍保留原有限制。

大量追加会使原生 ListView 的估算行高暂时不准确。定位在几个短暂布局帧内校正 ScrollIntoView，直到目标行实际进入可视区。它保留当前播放队列和多选状态；隐藏、导航或退出取消定位，歌曲、会话、歌单索引或页面变化会丢弃过期结果。请求失败保留已加载数据并允许重试。

## 已确认的图标方案

- 歌单：原播客的双音符，`E8D6 / F8B3`。
- 播客：耳机，`F8BA / F8BB`。
- 专辑：保留 Fluent Album，`E93C / F8B1`。

普通态及实心态都由包内 `NetEaseNEXTIcons.ttf` 提供。应用导航使用 `ms-appx:///Assets/Fonts/NetEaseNEXTIcons.ttf#NetEaseNEXT Icons`，不附带 Segoe 系统字体回退，没有采用系统唱片图标。字体仍由固定版本的微软 MIT Fluent System Icons 生成，并保留许可证；新增耳机两字形后为 75 个映射，11560 字节。

[最终图标预览](navigation-icons-preview-2026-10-24.png)是实际 WinUI FontIcon 渲染，左右为浅色/深色，每组为未选中/选中；测试数据不含真实账号内容。
