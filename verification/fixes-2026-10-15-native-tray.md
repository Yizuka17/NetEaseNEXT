# 原生托盘菜单与侧栏图标

便携包：`artifacts/win-x64-native-tray/NetEaseNEXT.exe`。

- 托盘菜单改为 USER32 的 `CreatePopupMenu` / `TrackPopupMenuEx`，移除独立 WinUI 菜单窗口及全局鼠标、前台窗口观察器。菜单关闭后释放 HMENU 和零尺寸工具窗口。主窗口隐藏时不恢复 XAML 界面计时器。
- 打开菜单前设置前台所有者，返回后发送 WM_NULL；外部点击、Esc、方向键和屏幕边缘布局由系统菜单处理。
- 菜单跟随 Windows 系统深浅色，高对比度保留系统处理。主题函数按可选导出解析，缺失时保留系统默认菜单。
- 旧菜单实际保留 WS_DLGFRAME / WS_EX_WINDOWEDGE，客户区宽 474 像素而窗口宽 480 像素；单独关闭 DWM 描边不足以去掉这层宿主边框。新菜单不再使用该宿主。
- 选中的发现、歌单、播客、动态、播放列表及设置图标切换为实心；未选中保留原线条图标。使用选择属性变化更新，不增加轮询，图标继承主题前景色。

Release 发布通过。23 项原生菜单与 Shell 检查通过，见 `native-tray-2026-10-15.json`；35 项既有界面检查通过，见 `sidebar-visual-2026-10-15.json`。通过 computer-use 实际查看深色和浅色系统菜单，深色菜单没有旧宿主的亮白外框；同时查看到实心的发现图标。

27 项启动、请求并行及原生菜单回归检查通过，见 `startup-native-tray-2026-10-15.json`。

运行检查覆盖真实 HMENU、原生前台所有者、中文命令、两种主题支持、隐藏状态、菜单取消不执行命令、原生句柄释放。自动输入的外部点击检查返回 `no screenshot targets found`，不将其记作真实点击验收；真实触屏菜单交互未验收。
