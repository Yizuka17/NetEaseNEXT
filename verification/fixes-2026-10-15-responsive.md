# 托盘菜单收起与启动等待

便携包：`artifacts/win-x64-responsive/NetEaseNEXT.exe`。退出旧版托盘进程后启动，保留目录内全部文件。

- 托盘菜单原先只依赖失焦事件，点击不改变前台窗口的位置时会漏掉关闭。菜单窗口改用可激活的工具窗口，并仅在打开期间监听外部按下和前台窗口变化。外部点击正常传递，不吞掉输入；关闭时立即移除监听，不增加后台轮询。
- API 原先在 C# 和 Node 两端都把整个请求串行化，慢的账号校验会阻挡页面请求。C# 只串行写管道，由独立读取循环按请求 ID 分发响应；Node 最多并发四个读取请求。保存、删除、发送等写入保持顺序，并作为读取队列的顺序边界。
- 取消一个已发送的读取只取消该等待者，保留其他请求。最后一个等待者取消时停止无用工作进程；写管道中途取消则重置受损通道。父管道关闭后立即退出，空闲退出仍为 15 秒。元数据缓存使用版本号，防止写入之后被旧响应重新填充。
- 工作进程启动、磁盘缓存解密和写入移到后台线程。共享会话的播放 API 客户端不再重复读取配置、解密登录会话。首页推荐和自己的歌单列表增加按会话隔离的五分钟加密缓存。
- 启动先读取缓存账号与播放状态，缓存头像独立于服务器校验开始显示。昵称和头像不再等待校验完成；账号校验及附属音质、互动信息不阻挡页面加载。缓存过期或缺失时仍须等待网络响应。
- 首次显示窗口不再先请求首页再取消；恢复到保存的页面后才启动附属请求。初始化时枚举全部字体改为打开设置时在后台扫描，保留当前字体选项及图标专用字体。

## 验证

API 契约测试 7 项通过，包含读取并行、并发上限、写入顺序边界、协议恢复、管道退出及互动请求参数；未执行真实互动写入。

专项检查见 `startup-menu-responsive-2026-10-15.json`：缓存账号不等待服务器、快请求先返回、乱序响应匹配、请求取消隔离、无用工作进程终止及重启、缓存版本、菜单内外边界、监听释放和按需字体扫描。界面定时器在慢请求期间持续执行。

外部窗口激活后菜单关闭及监听释放已经观察到。自动点击工具返回 `coordinate input geometry is unavailable`，未完成真实鼠标点击和触屏输入验收。专项记录的旧名称 `Real outside-click inspection dismisses the menu` 对应外部窗口激活检查，不代表工具成功发出了鼠标按下。

发布程序 130 项播放回归检查通过，见 `integration-responsive-2026-10-15.json`。后台播放 20.00 秒，主进程累计 CPU 265.6 毫秒、工作集 314.2 MiB、私有内存 156.5 MiB，两条 Node 工作进程退出。见 `background-responsive-2026-10-15.json`；该采样不是整机功耗或不同设备的性能保证。

最终发布程序另外运行生产启动路径，4 项检查通过，见 `startup-path-responsive-2026-10-15.json`：账号与页面初始化完成、保存的队列及当前歌曲恢复、保持暂停且不提前扫描字体。
