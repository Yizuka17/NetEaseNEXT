# 任务栏与托盘主题

便携包：`artifacts/win-x64-theme/NetEaseNEXT.exe`。

- 原先注册的 AppUserModelID 图标、窗口 RelaunchIconResource 和开始菜单快捷方式固定指向深色线条图标，托盘图标按应用界面主题选择；Windows 的系统颜色模式与应用颜色模式可以不同。
- 按系统颜色模式选择现有两份透明图标，保持造型不变。同步更新窗口大小图标、托盘、应用图标登记、开始菜单快捷方式及属于本应用的任务栏固定快捷方式的图标位置；保留固定快捷方式的启动目标和参数。
- 使用窗口主题通知处理变化，在主窗口隐藏时也更新图标；不增加主题轮询。退出后忽略图标更新，避免访问已关闭窗口。
- 旧式 Win32 托盘菜单换为临时原生 WinUI 菜单窗口，使用系统深浅色主题及实色主题背景。菜单不进入任务栏或切换器，按屏幕工作区及 DPI 定位；失去焦点或取消后关闭释放，主窗口保持隐藏。

## 验证

Release 构建与便携发布成功。已发布程序运行 `--smoke-test --shell-theme-check`，19 项检查全部通过，见 `shell-theme-2026-10-15.json`。覆盖系统与应用主题不同、两份图标资源、实际窗口图标句柄、Shell 图标属性、应用名称、主题通知在后台刷新、菜单颜色对比、200% 缩放下工作区边界、关闭释放及主窗口更新停止。

实际截图确认：暗色背景 `#FF202020`、白色文字；浅色背景 `#FFF3F3F3`、深色文字。系统设置未更改，测试通过程序内部指定主题验证两种菜单。

鼠标点击和方向键自动验证未完成：computer-use 工具激活这种临时菜单窗口时返回 `failed to activate captured window` / `foreground window did not report a process id`，菜单随失焦关闭。未据此声称验证了菜单命令的真实输入或 Windows 主题设置的人工切换；后台主题变化通过向本应用窗口发送主题通知验证。
