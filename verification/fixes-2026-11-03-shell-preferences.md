# 0.3.2.3：窗口、材质、下载译文与本地播放恢复

本次按用户要求只替换已有 v0.3.2 Release 的附件与说明；不提交或推送源码、不移动标签、不安装覆盖本机应用。包含之前 0.3.2.1、0.3.2.2 的本地歌单操作及上一首修复。

## 行为

- 侧栏自动展开阈值从 1100 降至 800 DIP，保留原生自动布局和手动收起；下载总览增加失败项数量，独立失败列表仍可使用。
- 设置增加默认开启的“记住窗口位置和大小”。记住普通窗口边界与最大化状态；最小化、全屏不覆盖正常边界。位置按最近显示器的工作区约束，避免窗口完全落在屏幕外；750ms 合并保存，关闭/隐藏前刷新保存，禁用后清除已记位置。
- Mica/Acrylic 默认恢复系统控制器原生参数，不再把着色和亮度混合统一设为同一数值。自定义滑块准确称为“着色强度”，保留旧配置含义并反向映射显示值；提供恢复系统默认。
- 修复最外层 FontHost 主题没有同步导致原生背景浅色、内容深色主题文字发白的问题。仅在系统背景已连接时处理默认配置回调，避免已分离窗口目标的配置访问错误。
- 下载读取原文与译文。标准音频歌词标签保存双语，附加标签分别保存原文/译文，离线播放恢复双语同步；同名 LRC 仍优先。无译文保留原文，已有下载文件不会自动改写。下一句译文提高可读性，当前句层级保持。
- 修复恢复队列时只接受正数在线歌曲 ID、丢弃负数本地 ID 的问题。恢复存在的本地文件、当前歌曲、队列、随机顺序和进度，同时恢复本地歌单页面；启动保持暂停，点击播放继续。失效文件跳过，切换至其他有效歌曲时不会套用旧进度；本地播放页启动不向在线 API 请求负数 ID 歌词。

## 检查

Release 构建：0 警告、0 错误。26 项窗口/侧栏/材质专项和 19 项译文/本地恢复专项分别连续三轮无失败。包括真实 WinUI 窗口保存/恢复、最大化/最小化/全屏、文件持久化、写入失败保留原配置、合成负坐标工作区、下载管线标签写入、离线双语歌词及加密播放快照往返。

回归：12 项上一首、19 项本地歌单操作、28 项下载标记（三轮）、32 项歌单下载流程、22 项原生功能、151 条完整回归记录（149 项断言、2 项资源采样）无失败。下载标记测试的文件删除增加有界等待，处理 Windows 解码器异步释放旧音源句柄的偶发现象；没有修改相应产品删除逻辑。诊断运行前后用户 settings.json 哈希一致。

原生 DWM 窗口截图见 [浅色下载页](shell-preferences-2026-11-03/native-after-light.png) 与 [最终深色设置页](shell-preferences-2026-11-03/native-after-dark-final.png)。[双语播放页](shell-preferences-2026-11-03/downloaded-translation-player.png) 是 XAML 渲染图，只验证内容和层级，不用来证明 DWM 材质。独立视觉评审及建议复核见 [评审记录](shell-preferences-2026-11-03/ui-review.md)。原生控件与原有布局体系保留，没有新增自定义动画或后台轮询。

本机 Windows 10 运行时报告 Acrylic 支持、Mica 不支持；Mica 明确回退纯色。已核对 Acrylic 实际窗口的浅色/深色外观及控制器默认参数；不将其扩大为 Windows 11 Mica 实机验收，也没有实际拔插多显示器或不同 DPI 迁移验收。没有更改系统透明效果设置。原生背景参数依据 [Microsoft 系统背景文档](https://learn.microsoft.com/en-us/windows/apps/develop/ui/system-backdrops) 与 [ResetProperties 文档](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.composition.systembackdrops.desktopacryliccontroller.resetproperties?view=windows-app-sdk-1.8)。

MSIX 0.3.2.3 使用既有发布者证书签名，签名和包内版本已核对，未包含 Node 运行时、会话或本地歌单数据。未新增修订包安装验收、真实付费音源下载或远端互动写入。包验证和远端替换证据分别记录在 `v0.3.2.3-package-2026-11-03.json` 与 `v0.3.2.3-release-replacement-2026-11-03.json`。
