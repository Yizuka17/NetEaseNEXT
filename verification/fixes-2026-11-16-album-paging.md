# 0.3.3.10 专辑详情与底部续页

专辑详情使用 `album` 已返回的元数据，显示各位专辑歌手的独立链接，以及有值的发行日期、类型、发行公司、语种。缺失字段不占位，单歌手对象可作为数组缺失时的后备；切换页面时先清除旧资料。长简介复用现有展开功能。每位歌手都以自身 ID 导航，而非固定打开第一位。

歌曲、专辑/歌手目录、播客、动态/消息、歌单入口和评论区的后续页使用原生 `ProgressRing`。加载行位于列表 Footer，随内容滚动，完成后设为 Collapsed，不保留空行。续页不再使用页面中央 Busy；首次进入页面的加载反馈保持原有行为。

触发入口包括接近底部的滚动、继续向上的滚轮与触摸手势、触控板操作完成和键盘向下翻页。内部 ScrollViewer 模板延迟创建时，在 Loaded、尺寸变化及首轮布局后补绑事件，卸载时解绑。请求进行中不会重复发起，末页不重复重载；失败保留已有行、页码及游标，在底部提供重试，也支持新一次底部手势重试。续页期间保留歌单批量移除的请求互斥。

歌单入口新增 offset 分页，解决仅取前 100 个歌单的问题。专辑接口一次返回全部歌曲，已完整载入时不制造续页请求。后续页判断优先使用接口的 hasMore/more，再以页大小推断，已知歌单总数也参与判断。页面切换或隐藏会取消请求并停止环形动画，恢复后保留原有续页语义。现有集合数量上限保持原规则。

## 验证

Windows 11 VirtualBox 3D 来宾通过 189 项原生检查：本次专辑/续页 23，歌曲体验 34，既有动效及封面/滚动 84，定位 14，上一首 12，综合功能 22。测试使用静音与合成接口，没有向真实账号写入数据；触摸入口已接入，未使用物理触屏做硬件验证。

专项覆盖每位专辑歌手的真实 Invoke 导航、字段缺失、长简介、已完整专辑不重载、重复手势去重、追加不跳过新歌曲、失败后重试、超过 100 个歌单、播客末页、取消陈旧请求、评论末页及批量移除互斥。截图见 [专辑资料](album-paging-2026-11-16/album-metadata.png)、[歌曲列表底部](album-paging-2026-11-16/track-bottom-ring.png)、[评论区底部](album-paging-2026-11-16/comment-bottom-ring.png)。

签名 MSIX 升级到 0.3.3.10 后，另行运行 23 项专项和 84 项动效回归。安装目录 DLL、MSIX 内 DLL 与通过检查的便携版一致，哈希和完整报告见 [summary.json](album-paging-2026-11-16/summary.json)。

采用 Windows App SDK 自带的 [WinUI ProgressRing](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.progressring?view=windows-app-sdk-1.8)，不替换模板或绘制自定义转圈图案。
