# 0.3.3.4 歌曲信息与列表交互

基于 GitHub `main` 的 `9248335`（0.3.3.3）继续修改，保留该版本的队列数据源稳定绑定、鼠标/触控选择协调和歌词滚动条修复。

播放器评论右侧新增透明背景的信息按钮，展示歌曲、歌手、专辑、时长和当前音质；本地文件可离线查看基本信息。歌曲详情使用已有 `song_detail` 接口。多个歌手的 ID 全部保存到播放快照，歌手入口可选择任意歌手。专辑页通过 `album_detail_dynamic` 读取状态，使用 `album_sub` 收藏/取消收藏；写入失败保留旧状态，成功后清理相关元数据缓存。

评论默认最热；选择最新/最热后保存到设置，其他歌曲和其他评论页面共用该偏好。播客曲目记录来源播客 ID，定位会按需加载后续节目页，并拒绝其他播客、旧路由、取消和过期登录会话的结果。

顺序选项增加倒序，保持列表的显示顺序，下一首朝原列表前方移动，上一首向后移动；倒序的“下一首播放”及批量插入遵循相同方向。自动播完倒序首曲后停止；手动切歌仍可首尾切换。模式通过播放快照保存。

随机“播放全部”从完整歌单 ID 集合抽取首曲，包括尚未加载的歌曲。先读取起点附近少量元数据并开始播放，再以每批最多 500 个 ID 补全队列，按原歌单顺序保存原始上下文。用户明确点击某首歌曲时仍播放所选歌曲。

歌曲行与播放队列的指示条保留原 480ms 拉伸/收缩曲线。父层在合成线程以 `scroll.Translation.Y` 跟随 ScrollViewer，指示条在内容坐标内运动，固定视口负责裁剪。虚拟化时隐藏无效标记，跨视口或重新进入列表时按上一首的索引从顶部或底部进入。队列首次展开先完成布局，再定位当前行。关闭动画时直接定位，滚动跟随继续生效。
