## 验证范围

Release x64 编译零警告、零错误；便携包 85 项原生运行检查通过，4 项 API 契约测试通过。包含真实 API 读取、原生 WinUI/MediaPlayer 运行检查和当前登录会话的社交读取。检查不会发送私信、发布评论、点赞或删除用户歌单。歌单删除和排序写入仅使用模拟请求验证参数。

会员专属高级音质、真实触摸长按和手写笔行为仍需对应权限与设备实测。表情使用系统 Unicode 符号呈现，不是网易云专用表情图片。歌词当前为逐行同步和双语展示，不含逐字变色。

后台播放在最终便携包的 20 秒样本中主进程消耗 375ms CPU，工作集约 286.1 MiB、私有内存约 157.5 MiB；Node 空闲退出、界面计时器停止和图片解绑均通过检查。这是进程样本，不是整机功率测量，不能据此宣称达到 2W。

应用内矢量图标和运行中的窗口/托盘图标随主题切换。当前为非 MSIX 便携应用，EXE 内嵌静态图标使用深色线条；Windows 的 MSIX 深浅色资源自动选择机制不直接作用于这一静态 ICO。

Windows 11 x64 上完成验证。头像居中和更换字体后的符号字形还单独通过快速检查，记录见 `visual-fixes-2026-10-14.json`。
