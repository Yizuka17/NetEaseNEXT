# v0.3.2 附件修订：上一首直接切换

## 原因与修改

`PlaybackService.PreviousAsync` 原先在播放进度超过三秒时先归零并返回，因此第一次点击只会重播当前歌曲，第二次才会切换到上一首。

删除该分支后，每次请求都会按现有播放队列选择上一首。播放器按钮和系统媒体按钮原本就调用同一方法，沿用这条入口。保持首曲回绕到队尾、单曲队列重播和空队列忽略请求的行为；上一首无法加载时保留当前音源与进度。

沿用用户要求，仅替换现有 v0.3.2 Release 的附件与说明，不推送源码、不移动标签、不覆盖本机已安装包。MSIX、程序集及文件修订号为 0.3.2.2；设置页主版本仍为 0.3.2。
