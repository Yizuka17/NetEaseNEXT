# v0.3.2 附件修订：本地定位、移除文件与版本标识

按用户要求只替换既有 v0.3.2 Release 的附件和说明，不新建 Release，也不移动源码标签。本地源码保留改动，安装包修订号为 0.3.2.1，以支持已安装 0.3.2.0 的用户直接升级；设置页显示主版本 0.3.2。

## 行为

- 本地歌单复用“正在播放”悬浮定位按钮。当前本地文件按路径匹配；在线播放已下载歌曲时可按下载文件或有效来源 ID 关联到本地列表。点击滚动到实际歌曲行，不请求歌曲详情，保留多选。无对应歌曲或窗口隐藏时不显示按钮。
- 单曲与批量移除先显示原生确认框，默认保留音频。“同时删除本地音频文件”明确选中后，主按钮变为“移除并删除”。取消不修改文件或歌单。
- 保留文件时，仅移除所选歌单引用；文件夹歌单保存路径排除记录，重新扫描或重启后也不会自动加回。更换或取消目录绑定会重置这组排除记录。
- 删除只处理选中的路径，释放正在播放的对应文件，并清理同一路径在本地库、其他歌单、播放队列和下载索引中的引用。其他目录里的同曲副本保留。音频被占用或无法删除时保留该文件及其歌曲记录，批量操作反馈失败项。
- 在接触音频前先验证本地库可保存，明显的保存失败不会继续删除文件。删除与保存不是跨文件系统事务；操作系统故障仍不构成回收或撤销保证。
- 设置页去除写死的“NetEaseNEXT 0.2”，改用程序集版本生成标识；旧 Inno 安装脚本中的 0.2.0 标识一并更新。MSIX 版本与程序集修订号为 0.3.2.1。
